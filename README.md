# Universal Dark

Личное расширение для Chrome, Edge, Brave, Opera, Vivaldi и других браузеров на Chromium. Включает тёмную тему на всех сайтах в стиле Windows 11. Если у сайта уже есть своя тёмная тема, расширение само отключается.

## Установка

1. Откройте `chrome://extensions` (в Edge: `edge://extensions`, в Brave: `brave://extensions`).
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите эту папку.
4. Чтобы тема работала в режиме инкогнито, откройте «Сведения» у расширения и включите «Разрешить использование в режиме инкогнито».
5. Для локальных файлов (`file://`) включите там же «Разрешить доступ к URL-адресам файлов».
6. После правок кода нажмите на карточке расширения кнопку обновления. Если сервис-воркер не подхватил новый файл, удалите расширение и загрузите заново.

## Как работает

- Сразу при загрузке страницы ставится тёмный фон и `color-scheme: dark`, поэтому белой вспышки нет.
- Движок перекрашивает все правила CSS: светлые фоны становятся тёмными поверхностями (`#202020`, `#2b2b2b`), тёмный текст светлеет, яркие акценты (кнопки, ссылки) сохраняют оттенок. Тот же алгоритм применяется к inline-стилям, CSS-переменным (в том числе `hsl(var(--x))` и Tailwind), shadow DOM, iframe, динамически добавленным стилям и таблицам стилей с других доменов.
- Тёмные логотипы и иконки на прозрачном фоне (PNG/SVG) инвертируются, чтобы не пропадали. Фотографии, видео и цветные изображения не трогаются.
- **Сайт уже тёмный:** страница замеряется без наших стилей. Если большинство видимых областей тёмное, расширение отключается. Если сайт сам переключится на светлую тему, расширение включится снова.
- **Запасной режим:** если после перекраски страница всё ещё светлая, применяется мягкая инверсия всей страницы с возвратом оригинальных картинок.

## Управление

- Значок расширения: включить или выключить тему, следовать ли теме системы, выключить на текущем сайте.
- `Alt+Shift+D`: быстро включить или выключить везде. Клавишу можно изменить на `chrome://extensions/shortcuts`.
- По умолчанию тема включена всегда, но выключается, если в системе светлая тема. Это можно отключить в окне расширения.

## Ограничения Chromium

Расширения не могут менять внутренние страницы браузера (`chrome://`, `edge://`, страница новой вкладки), интернет-магазин расширений и встроенный просмотрщик PDF. Они следуют тёмной теме самого браузера.

## Структура

| Файл | Назначение |
|---|---|
| `manifest.json` | Манифест MV3, подключение скриптов |
| `content/hook.js` | Работает в мире страницы: сообщает о `insertRule`, `replace` и `attachShadow` |
| `content/color.js` | Разбор цветов и палитра тёмной темы |
| `content/transform.js` | Перекраска значений, деклараций и правил CSS |
| `content/detect.js` | Замер фона: тёмная страница или светлая |
| `content/pixels.js` | Определение «тёмных логотипов» |
| `content/engine.js` | Управление: наблюдение за страницей, состояния, запасной режим |
| `background.js` | Загрузка чужих CSS и картинок, горячая клавиша |
| `popup/` | Окно настроек |

Палитру можно поправить в `content/color.js` (функции `mapBg`, `mapFg`, `mapBd`) и в `EARLY_CSS` в `content/engine.js`.

## Обновления

Расширение раз в 12 часов смотрит последний релиз в GitHub (`ignatovmax1/universal-dark`). Если вышла новая версия, на значке появляется зелёная метка **NEW**, а в окне расширения кнопка «Доступна версия X: скачать». Проверить вручную можно в окне расширения: «Обновления» → «Проверить сейчас».

Репозиторий приватный, поэтому для проверки нужен токен: GitHub → Settings → Developer settings → Fine-grained tokens → доступ только к репозиторию `universal-dark`, право **Contents: Read-only**. Вставьте токен в «Обновления» в окне расширения. Он хранится только в вашем браузере.

Chrome не умеет автоматически ставить обновления распакованных расширений из GitHub, поэтому после «скачать» нужно:
1. Скачать zip со страницы релиза и распаковать поверх папки расширения (или `git pull`, если папка является клоном репозитория).
2. В `chrome://extensions` нажать кнопку обновления на карточке расширения.

### Выпуск новой версии

1. Увеличьте `version` в `manifest.json` (например, `1.0.1`).
2. Закоммитьте и отправьте изменения:
   ```bash
   git add -A && git commit -m "v1.0.1" && git push
   ```
3. Создайте и отправьте тег с тем же номером:
   ```bash
   git tag v1.0.1 && git push origin v1.0.1
   ```

GitHub Actions (`.github/workflows/release.yml`) проверит, что тег совпадает с версией в манифесте, соберёт `universal-dark-v1.0.1.zip` и опубликует релиз.
